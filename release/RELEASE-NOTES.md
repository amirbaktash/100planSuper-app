# یادداشت انتشار — 100plan (DARIC Token) 1.0.0-beta

## وضعیت و هشدار

این بسته یک **پروتوتایپ نمایشی/توسعه‌ای** است، نه محصول مالی عملیاتی. داشبورد داده‌های نمونهٔ ثابت دارد و به سرویس‌های مالی یا قراردادهای مستقر وصل نیست. موجودی، قیمت، NAV، KYC، و تراکنش‌ها واقعی نیستند؛ از آن برای جابه‌جایی پول یا واردکردن اطلاعات شخصی استفاده نکنید.

این انتشار فقط سورس پروژه‌های Android/iOS و خروجی وب را شامل می‌شود؛ APK/IPA امضاشده ارائه نشده است. شبکه و آدرس قراردادهای مستقر، گزارش ممیزی، مجوز سراسری پروژه، سیاست حریم خصوصی و حوزهٔ قضایی هدف در این بسته مشخص نشده‌اند.

## محتوا

- `web/` — build وب/PWA؛ نصب کامل PWA نیازمند HTTPS (یا localhost روی همان دستگاه برای آزمایش) است.
- `android/` — پروژهٔ Gradle؛ JDK 17، Android SDK 36 و keystore برای APK انتشار لازم است.
- `ios/` — پروژهٔ Xcode/SPM؛ ساخت IPA به macOS، Xcode و signing/provisioning متناسب نیاز دارد.
- `source/` — سورس داشبورد، قراردادها، بسته‌ها، سرویس‌ها و اسناد.
- `scripts/` — `sync-web.sh`, `build-apk.sh`, `build-ipa.sh` برای build/sync محلی.
- `README-INSTALL.md` — دستورالعمل دقیق نصب، sync، امضا و بررسی خروجی.
- Frontend با Vite `8.3.6` build می‌شود؛ هنگام بسته‌بندی `npm audit --audit-level=moderate` اجرا شد و در زمان این build، آسیب‌پذیری npm گزارش نشد.

## محدودیت‌های اعتبارسنجی

- Build وب/PWA قابل بررسی محلی است؛ APK/IPA در این محیط ساخته نشده‌اند.
- اسکریپت verification ادعای اجرای تست قرارداد یا E2E ندارد؛ Playwright/Hardhat به‌عنوان runner کامل این مخزن پیکربندی نشده‌اند.
- وضعیت استقرار قرارداد، ممیزی، ذخایر و انطباق حقوقی با این بسته اثبات نمی‌شود.
